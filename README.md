# Golden Retreats — Landing Page

A calm, minimal landing page for Vercel (Next.js App Router + Tailwind).

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push this repo to GitHub
2. In Vercel: **New Project → Import Git Repository**
3. Framework preset: **Next.js** (auto-detected)
4. Deploy
